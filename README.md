# Русская локализация BitCraft Online

Неофициальный перевод для Windows. Выпуск от 10 ноября 2026 года содержит 970 правок из прежнего набора переводов и согласованных рабочих списков. Это продолжающаяся работа, полной вычитки всей игры пока нет.

## Установка

1. Скачайте [последний выпуск](https://github.com/Hitachi-ux/bitcraft-ru-localization/releases/latest) и файл `BitCraft-RU-localization.zip` (около 1,5 ГБ).
2. Закройте BitCraft, распакуйте архив и запустите `INSTALL.bat`.
3. В Steam откройте BitCraft Online → **Управление → Просмотреть локальные файлы**. Вставьте путь к папке игры в окно установщика.
4. Дождитесь сообщения об успешной установке.

Готовый архив содержит переведённый игровой пакет и установщик. Python не требуется. Оригиналы сохраняются в `BitCraft_Data/StreamingAssets/aa/bitcraft-ru-backup`.

## Откат

Закройте игру и запустите `RESTORE.bat` из распакованного архива, укажите ту же папку игры. Если контрольные суммы не совпадают, восстановите файлы через проверку целостности в Steam.

## Самостоятельная сборка и правки

В репозитории лежат `translations.json`, исходный установщик и рабочие таблицы в `review/`. Чтобы собрать перевод самостоятельно, нужны Windows, Python 3.10+, `py` launcher, UnityPy и около 32 ГБ оперативной памяти. `INSTALL.bat` в корне репозитория собирает пакет из оригинальных файлов игры. Игрокам проще использовать готовый архив из Releases.

Проект сообщества, не связанный с разработчиками BitCraft Online. Игровые файлы не включены в Git-репозиторий.
