# Русская локализация BitCraft Online

Неофициальный, постепенно редактируемый перевод для BitCraft Online на Windows. В текущем наборе 510 изменений: названия ресурсов, существ, рыб и часть имён персонажей и интерфейса. Перевод не претендует на полную вычитку игры.

Репозиторий содержит только наши изменения и установщик; игровые ресурсы не распространяются. Установщик берёт пакет из вашей установленной игры, пересобирает его, обновляет контрольную сумму и сохраняет оригиналы.

## Требования

- Windows и установленная Steam-версия BitCraft Online, совпадающая с проверенной сборкой. Установщик сверяет SHA-256 обоих файлов и остановится при несовпадении.
- Python 3.10 или новее с `py` launcher и доступом к интернету для установки UnityPy из PyPI.
- Несколько гигабайт свободного места и памяти: игровой пакет большой, пересборка может занимать несколько минут.

## Установка

1. Закройте BitCraft.
2. На странице репозитория выберите **Code → Download ZIP**, распакуйте архив полностью.
3. Запустите `INSTALL.bat`. При первом запуске он создаст локальное виртуальное окружение и установит библиотеку из `requirements.txt`.
4. В Steam откройте BitCraft Online → **Управление → Просмотреть локальные файлы**. Скопируйте путь к открывшейся папке `BitCraft Online`, вставьте его в установщик и нажмите Enter.
5. Дождитесь сообщения об успешной установке, затем запустите игру.

Установщик не скачивает и не распространяет игровые файлы. Оригиналы сохраняются в папке `BitCraft_Data/StreamingAssets/aa/bitcraft-ru-backup` внутри игры. Не удаляйте их до проверки игры.

## Откат

Закройте игру и запустите `RESTORE.bat`, указав ту же папку игры. Откат проверяет резервные копии и установленные файлы. Если игра успела обновиться и проверка не проходит, восстановите оригиналы через проверку целостности файлов Steam. Резервная папка после отката сохраняется; для повторной установки сначала перенесите её в безопасное место.

## Совместимость

Проверяемый оригинальный пакет имеет SHA-256 `123e86f6c6ddc9b21c081d11a329b42e3fae853372f33793e10c74c37c16af11`. После обновления игры контрольные суммы могут измениться — в этом случае текущий установщик не будет менять файлы. Совместимость с последующими обновлениями не гарантируется.

## Устройство

`translations.json` содержит только изменённые строки и английские ключи. `localize.py` проверяет ключи, параметры строк и версию игры, проверяет собранный пакет повторным чтением и обновляет его CRC в каталоге. Для сборки используется UnityPy. Для изменения перевода в репозитории необходимо обновить `translations.json`.

Проект сообщества, не связан с разработчиками BitCraft Online.
Рабочие таблицы для совместной редакции находятся в папке `review/`. Правки в этих таблицах не попадают в игру автоматически: перед новым выпуском нужно обновить `translations.json` и проверить установку.
